🌍 WanderLust

WanderLust is a full-stack travel accommodation web application inspired by Airbnb. It allows users to explore destinations, create and manage property listings, upload property images, write reviews and ratings, and securely authenticate using signup and login functionality.

The application follows the MVC architecture and is built using Node.js, Express.js, MongoDB, Mongoose, EJS, and Bootstrap. MongoDB Atlas is used for cloud database storage, while Cloudinary is used for image management. The application is deployed on Render.

✨ Key Features
🏠 Create, view, edit, and delete property listings
🔐 User signup, login, logout, and authentication
👤 Authorization for listing owners
⭐ Add ratings and reviews to properties
🗑️ Delete reviews with authorization
📷 Cloud-based image upload and storage using Cloudinary
🔎 Search properties by destination
🏷️ Property categories and filtering
💰 Tax/price display functionality
🗺️ Location/map integration
💬 Flash messages for user feedback
✅ Server-side validation and error handling
📱 Responsive user interface
☁️ MongoDB Atlas cloud database
🚀 Deployed on Render
🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript, EJS, Bootstrap
Backend: Node.js, Express.js
Database: MongoDB Atlas, Mongoose
Authentication: Passport.js, Passport Local, Passport Local Mongoose
Image Storage: Cloudinary, Multer
Validation: Joi
Session Management: Express Session, Connect Mongo
Deployment: Render
Version Control: Git & GitHub
